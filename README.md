## 🚀 Основной контекст проекта (v8.8.3)

CRM-система **A29 CRM** — это высокоскоростной веб-инструмент для учета заказов, клиентов, подрядчиков, расчетов с плательщиками и финансовой аналитики рекламного агентства.

Приложение сочетает удобство и скорость таблицы уровня Google Sheets / Excel с надежностью облачной мультипользовательской СУБД Turso SQLite и защищенным серверным API.

### 🛠️ Технологический стек:
* **Фронтенд**: React 19, TypeScript, Vite 7, TailwindCSS 4, Lucide React (иконки), MathJS (формулы).
* **Бэкенд**: Vercel Serverless Functions (`api/*.ts` на `@vercel/node`).
* **База данных**: Turso Cloud SQLite (`@libsql/client/web`).
* **Безопасность**: Защита эндпоинтов сессионными HMAC-токенами (`Authorization: Bearer <token>`).
* **ИИ-интеграция**: Мультимодальный разбор текста и изображений заказов через OpenRouter API.
* **Фавиконка**: Брендовая SVG-фавиконка [`public/favicon.svg`](file:///c:/DEV/2026/CRM%202026/public/favicon.svg).

## 🔐 Безопасность и архитектура прав доступа

В версии **v8.8.0** внедрена строгая серверная аутентификация и защита API:

1. **Аутентификация через базу данных Turso**:
   * Все учетные записи (включая Администратора) хранятся и валидируются исключительно через таблицу `users` в базе данных Turso DB.
   * При успешном входе сервер генерирует криптографически подписанный сессионный токен (HMAC-SHA256).

2. **Защита серверного API (`api/*.ts`)**:
   * Все конечные точки API (`/api/orders`, `/api/clients`, `/api/contractors`, `/api/payers`, `/api/users`, `/api/history`, `/api/salary`, `/api/ai-parse`) защищены валидатором токена [`api/auth-helper.ts`](file:///c:/DEV/2026/CRM%202026/api/auth-helper.ts).
   * Прямой неавторизованный доступ без валидного токена блокируется с ошибкой `401 Unauthorized`.

3. **Разделение ролей**:
   * **`admin` (Главный Администратор)**:
     * Имеет доступ ко всему функционалу и специальной вкладке **«Пользователи»** ([`UsersTab.tsx`](file:///c:/DEV/2026/CRM%202026/src/components/UsersTab.tsx)) для создания учетных записей, смены паролей и назначения ролей.
     * **«🛡️ Панель Администратора: Просмотр данных»**: Селектор над таблицей для просмотра общей сводки агентства (`🌐 Все менеджеры`) или переключения в базу отдельного сотрудника.
     * **Защита от потери данных**: При удалении аккаунта сотрудника требуется ввод логина для подтверждения; данные (заказы, клиенты, подрядчики) **не удаляются**, а автоматически переназначаются в общую базу агентства (`usr_alex`).
   * **`user` (Менеджер)**:
     * Работает исключительно со своими заказами, клиентами, подрядчиками и счетами (изоляция по `user_id`).
     * Административная панель и вкладка управления пользователями скрыты.

## 📋 Модули и ключевые возможности

### 1. Заказы ([`OrdersTab.tsx`](file:///c:/DEV/2026/CRM%202026/src/components/OrdersTab.tsx))
* **Формулы по стандарту Excel / 1С**: Ячейки в колонке «Сумма реал.» отображают готовый рассчитанный результат (`15 408 ₽`), а формула (`=200*16+10`) доступна при редактировании или в верхней строке формул.
* **Сквозной (глубокий) поиск**: Поисковая строка мгновенно ищет по продукции, клиентам, подрядчикам, описаниям работ, формулам расходов и примечаниям.
* **Динамическое раскрытие подтаблиц**: Найденные подрядчики автоматически раскрываются во время ввода поискового запроса.
* **Кнопка «▲ Свернуть все»**: Мгновенно сворачивает все открытые подтаблицы подрядчиков в 1 клик.
* **Навигация клавишами**: Поддержка клавиш `←` `→` `↑` `↓` и `Enter` для перемещения по ячейкам таблицы.

### 2. Подрядчики и Затраты (Подтаблица в заказах)
* **Синхронизация с Edit-Bar**: Клик по ячейке подрядчика («Описание работ», «Формула (=)», «Примечание») передает текст в верхнее окно ввода.
* **Удобные значения по умолчанию**: Новые строки добавляются со статусом `-- Выберите --` и чистым полем ввода формулы.

### 3. Интеллектуальный ввод заказов с ИИ ([`AiOrderModal.tsx`](file:///c:/DEV/2026/CRM%202026/src/components/AiOrderModal.tsx))
* **Мультимодальное распознавание**: Вставка текста переписки из WhatsApp/Telegram или загрузка скриншота/фото счета.
* **Автоматическое извлечение**: ИИ сопоставляет существующих клиентов, подрядчиков, расчетные счета и формирует готовый черновик заказа с формулами.

### 4. Отчеты и Сверка ([`ReportsTab.tsx`](file:///c:/DEV/2026/CRM%202026/src/components/ReportsTab.tsx))
* 📅 **Месячный отчет**: Сводка по выручке, затратам, валовой прибыли и фонду ЗП.
* 👤 **Отчет по контрагенту**: Детализация реализации и валовой прибыли по заказчикам с возможностью прямого редактирования **«Счет №»**, **«Получатель оплаты»** и чекбокса **«Оплачено»** прямо из отчета с моментальным сохранением в БД.
* 🏗️ **Отчет сверки по подрядчику**: Интерактивное прямое редактирование сумм и формул расходов с живым фильтром сверки (🔘 **Все**, 🔘 **✓ Сверено**, 🔘 **⏳ Не сверено**).
* 💰 **Зарплатный расчет**: Расчет ЗП с учетом процента от прибыли, платежей по картам, собственных монтажей менеджера и фиксацией ведомостей в БД.
* **Сохранение состояния**: Все параметры отчетов кэшируются в `localStorage` и не сбрасываются при переключении между вкладками.

### 5. Журнал регистраций и снапшоты ([`HistoryTab.tsx`](file:///c:/DEV/2026/CRM%202026/src/components/HistoryTab.tsx))
* Хранение полной истории изменений базы данных в Turso DB.
* Мгновенный откат состояния базы данных к любому историческому снимку в 1 клик.

### 6. Выгрузка и Загрузка JSON ([`NavigationTabs.tsx`](file:///c:/DEV/2026/CRM%202026/src/components/NavigationTabs.tsx))
* Экспорт всей базы или отдельных справочников (Клиенты, Подрядчики, Заказы) в JSON для резервного копирования.

### 7. Мобильная адаптивность & Тёмная тема ([`index.css`](file:///c:/DEV/2026/CRM%202026/src/index.css))
* **Dark Mode**: Высококонтрастный текст, темные подложки (`#1c1f26`), полупрозрачные (45% opacity) выполненные заказы для фокусировки на активных задачах.
* **Адаптивность**: Горизонтальный скролл вкладок и компактное Burger Menu для смартфонов.

## ⚙️ Переменные окружения (`.env`)

Создайте файл `.env` в корне проекта (на основе [`.env.example`](file:///c:/DEV/2026/CRM%202026/.env.example)):

```env
# Подключение к облачной БД Turso (SQLite)
TURSO_DATABASE_URL=libsql://your-db-name.turso.io
TURSO_AUTH_TOKEN=your-turso-auth-token

# Секретный ключ для подписи сессионных токенов API (опционально, по умолчанию используется TURSO_AUTH_TOKEN)
AUTH_SECRET=your-secure-random-secret-key-32-chars

# Настройки ИИ-распознавания заказов через OpenRouter (опционально)
OPENROUTER_API_KEY=sk-or-v1-your-openrouter-key
OPENROUTER_MODEL=openai/gpt-4o-mini
```

## 💻 Локальный запуск и Деплой

### 1. Запуск локально:
```bash
# 1. Установка зависимостей
pnpm install

# 2. Создание таблиц и начальная инициализация БД Turso
pnpm migrate

# 3. Запуск в режиме разработки (Vite + локальный API dev-сервер)
pnpm dev
```
Откройте в браузере: `http://localhost:5173`.

### 2. Сборка для продакшена:
```bash
pnpm build
```

### 3. Деплой на Vercel:
При любом коммите и push в ветку `main`:
* **Vercel**: Автоматически собирает фронтенд и разворачивает функции API (`/api/*`).
* **GitHub**: [`github.com/penkin-repo/CRM-2026`](https://github.com/penkin-repo/CRM-2026)
* **GitVerse**: [`gitverse.ru/penkin-repo/crm-2026-A29`](https://gitverse.ru/penkin-repo/crm-2026-A29)
