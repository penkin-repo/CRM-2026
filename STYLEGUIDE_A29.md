# Руководство по стилю оформления A29 CRM

Этот документ содержит полное описание дизайн-системы и правил оформления веб-интерфейса **A29 CRM**. Предназначен для разработчиков и ИИ-ассистентов для сохранения единого стилистического единообразия.

---

## 🎨 1. Цветовая палитра A29 CRM

### Основные акцентные цвета
- **Фирменный жёлтый акцент (Основной)**: `#ffcc00`
- **Жёлтый градиент (Верх)**: `from-[#ffdb4d] to-[#ffcc00]`
- **Тень / Бордюр жёлтых элементов**: `#d9a800`
- **Фон активной строки (Row Selection)**: `#ffe97d`
- **Ховер строки (Row Hover)**: `#fff9d6`
- **Фон выделенного блока / Табличной части**: `#fffef2`

### Нейтральные и статусные фоны
- **Фон приложения (Body Background)**: `#e5e8ed`
- **Фон командной панели (Command Bar)**: `#f0f2f5`
- **Фон неактивных вкладок**: `#e6e9ed`
- **Бордюр таблиц и панелей**: `#b8bdc5`
- **Бордюр ячеек таблиц (Sheet Cell Border)**: `#c9ced6`
- **Границы строк в таблицах**: `#c9ced6`
- **Нежно-красная подсветка незаполненных обязательных ячеек (`.cell-unfilled`)**: `#fff0f0` (светлая тема), `rgba(185, 28, 28, 0.22)` (тёмная тема), при наведении `#ffe6e6`. При активном редактировании перекрывается золотистой рамкой ячейки.

### Типографика и цвета текста
- **Основной цвет текста**: `#1c1d1f` (Черно-серый)
- **Второстепенный текст**: `#555a64`
- **Текст в шапках колонок**: `#333740`
- **Шрифт**: `"Segoe UI", system-ui, -apple-system, BlinkMacSystemFont, Arial, sans-serif`
- **Базовый размер шрифта ячеек**: `12px` (компактная плотность)

## 📐 2. Структура интерфейсных блоков

### А. Верхняя шапка (Top Header)
- Градиентная плашка `from-[#ffcc00] via-[#ffd426] to-[#ffcc00]`
- Красный бейдж `A29` (`bg-red-600`, бел. текст, скругление `rounded-md`)
- Текст темы и текущего пользователя на светлом плашке `#fff5a8` с границей `#e5ba00`

### Б. Верхние вкладки навигации (Tabs Bar)
- Контейнер: `#f0f2f5` с границей `#b8bdc5`
- **Активная вкладка**: `bg-[#ffcc00] border-[#d9a800] text-[#1c1d1f] font-bold`
- **Неактивная вкладка**: `bg-[#e6e9ed] text-[#44474e] hover:bg-white`

### В. Панель команд и фильтров (Command Bar)
- Фон: `#f0f2f5`, нижняя граница `#b8bdc5`
- Поля ввода: `bg-white border-[#b8bdc5] text-xs font-medium`
- Кнопка первичное действие (`+ Создать заказ`): `bg-gradient-to-b from-[#ffdb4d] to-[#ffcc00] border-[#d9a800] text-[#1c1d1f] font-bold hover:from-[#ffcc00] hover:to-[#e6b800]`

### Г. Табличная сетка (Sheet Grid)
CSS-классы заданы в `src/index.css`:
```css
.sheet-grid {
  border-collapse: collapse;
  width: max-content;
  min-width: 100%;
  table-layout: fixed;
  font-size: 12px;
}

.sheet-header {
  border: 1px solid #b8bdc5;
  background: linear-gradient(180deg, #f4f6f8 0%, #e2e6eb 100%);
  font-size: 11px;
  font-weight: 700;
  color: #333740;
  height: 28px;
  padding: 0 6px;
  position: sticky;
  top: 0;
  z-index: 5;
}

.sheet-cell {
  border: 1px solid #c9ced6;
  height: 26px;
  font-size: 12px;
  padding: 0 6px;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
  background: white;
  line-height: 26px;
}
```

### Д. Табличные части (Sub-tables / Подрядчики)
- Контейнер: `#fffef2` с левым акцентным бордюром 4px `border-l-[#ffcc00]`
- Заголовок табличной части: `#333740 font-extrabold text-xs`

### Е. Подсветка статусов заказов (Active / Completed Rows)
- **В работе (Active)**: `bg-[#fffef2]`, при наведении `hover:bg-[#fff9d6]`. Фирменный светлый тепло-желтый тон A29 для выделения всех активных задач в работе.
- **Выполненные (Completed)**: Приглушенный нейтральный фон `bg-[#f1f5f9]` с полупрозрачностью `opacity-60 hover:opacity-95`. Приглушает завершенные заказы, разгружая визуальное восприятие.

### Ж. Подсветка незаполненных обязательных ячеек (.cell-unfilled)
- **Стиль**: пастельный нежно-красный фон `#fff0f0` (для тёмной темы `rgba(185, 28, 28, 0.22)`), при наведении `#ffe6e6`.
- При фокусе ячейки (`.sheet-cell-active` или `:focus-within`) фон и контур перекрываются янтарным стилем активной ячейки.
- **Обязательные поля в строке Заказа**:
  1. Дата (`order.orderDate`)
  2. Клиент (`order.clientName`)
  3. Изделие (`order.productDescription`)
  4. Себестоимость/Подрядчик (`order.contractorCosts === 0`)
  5. Реализация (`order.saleAmount === 0`)
  6. Получатель счета (`!order.paymentReceiverId`)
  7. № счета (`!order.paymentNote` при безналичной оплате)
  8. Оплата (`!order.paymentReceived`)
- **Обязательные поля в строке Подрядчика**:
  1. Подрядчик (`!cr.contractorId`)
  2. Описание работ (`!cr.description`)
  3. Стоимость / Формула (`!cr.costValue || cr.costValue <= 0`)
  4. Плательщик (`!cr.payerId`)
  5. Оплата (`!cr.paid`)

### З. Интерактивная плашка вычисления формул (Live Formula Preview Badge)
- При вводе математических выражений в ячейках формул (`Реализация` в заказе и `Формула (=)` у подрядчиков) строго поверх ячейки отображается плавающая подсказка:
  - Класс: `.formula-preview-badge` (стили в `src/index.css`).
  - Позиционирование: `position: absolute; bottom: calc(100% + 6px); right: 0; z-index: 9999; pointer-events: none;`.
  - Треугольная стрелка-указатель снизу плашки (`::after`), направленная на ячейку.
  - Оформление: контрастный темный фон `#1c1d1f`, золотистая граница `border: 1.5px solid #e5ba00`, моноширинный шрифт, золотистый знак `=` (`.formula-sign` с цветом `#f59e0b`) и белый текст вычисленной суммы (`.formula-val` с цветом `#ffffff`).
  - Ячейка (`td.sheet-cell-active`) и строка (`tr:has(td.sheet-cell-active)`) получают `overflow: visible !important;` и повышенный `z-index`, благодаря чему всплывашка никогда не обрезается таблицей и всегда парит поверх всех строк и шапки.
  - Поведение: мгновенно обновляется при каждом символе; исчезает сразу при потере фокуса ячейки.

### И. Единый стиль кнопок строки действий (Order Action Toolbar)
- Все кнопки в колонке действий заказа (включая кнопку копирования `#ID`, Google Sheets TSV, предпросмотр, дублирование, удаление) имеют **строго одинаковую высоту `22px`** (`h-[22px] min-h-[22px] leading-none`):
  - Квадратные иконки: `h-[22px] w-[22px] p-0 shrink-0`.
  - Кнопка `#ID`: `h-[22px] px-1.5 shrink-0 text-[11px] font-mono font-bold leading-none`.
  - Цветовая схема: `bg-white border-[#c9ced6] text-[#555a64] hover:bg-[#fff9d6] hover:border-[#d9a800] hover:text-[#1c1d1f]`.
  - Запрещено использовать цветные фоны (синие, фиолетовые бейджи) или разную высоту для кнопок в одной строке действий.

### К. Снятие фокуса с ячеек таблицы
- При клике в любое свободное место экрана (вне ячеек таблицы и строки редактирования), а также при нажатии клавиши `Escape`, активный фокус ячейки (`activeCell`) сбрасывается, снимая янтарную рамку.

### Л. Модальное окно детализации зарплатного расчета (Salary Breakdown Modal)
- Предоставляет пользователю полную математическую и строковую расшифровку зарплатной ведомости.
- Формат: минималистичный стиль `Plain-text / Notepad` в блоке `<pre>` с шрифтом `font-mono text-xs`.
- Структура текста:
  1. Базовый фонд (процент от прибыли, общая реализация, затраты, прибыль, список заказов с номерами, датами, клиентами и суммами).
  2. Поступления по счетам (+ / -) с детализацией по заказам.
  3. Работы менеджера (+) с перечислением строк работ, описаний и счетов.
  4. Выплаты подрядчикам (+ / -) по счетам списания.
  5. Итоговый математический расчет к выплате.
- Интерактивность:
  - Кнопка «Скопировать весь текст» с индикатором успешного копирования («✓ Скопировано в буфер!»).
  - Закрытие по клавише `Escape`, кнопке `✕` или клику на фон.

## 🛠 3. Правила для ИИ при создании новых элементов
1. **Сохраняйте компактность A29 CRM**: Высота строк таблицы — `26px`, высота кнопок — `24px-28px`, шрифт `12px`.
2. **Используйте фирменные желтые акценты**: Все ключевые кнопки используют желтый стиль (`bg-[#ffcc00]`).
3. **Строгая граница ячеек**: Все ячейки и инпуты внутри таблиц имеют чёткие границы `#c9ced6` или `#b8bdc5`.
4. **Выделение выбранной строки**: Активная строка или строка под курсором получает класс `.sheet-row-active` или ховер `hover:bg-[#fff9d6]`.
5. **Мягкое гашение выполненных элементов**: Завершенные/архивные документы выводите с уменьшенной прозрачностью (`opacity-60`), чтобы сфокусировать внимание на активных задачах.
6. **Подсветка незаполненных обязательных полей**: Применяйте класс `.cell-unfilled` к незаполненным ячейкам заказа и подрядчиков, не ломая фоны активных и выполненных строк.
7. **Живой расчет формул**: Для ячеек с поддержкой математических выражений реализуйте контекстную всплывающую плашку предпросмотра результата.
8. **Единообразие кнопок**: Кнопки действий таблицы оформляются в белом цвете с бордюром `#c9ced6` и мягким золотистым ховером `#fff9d6`.
9. **Снятие фокуса**: Любые интерактивные таблицы должны корректно сбрасывать выделение ячеек при клике вне таблицы и по клавише `Escape`.
10. **Чистый текстовый экспорт отчетов**: Для модулей экспорта расчетов в блокнот или мессенджеры оформляйте данные в чистом моноширинном текстовом виде без лишних HTML-тегов, с кнопкой копирования в буфер в один клик.
